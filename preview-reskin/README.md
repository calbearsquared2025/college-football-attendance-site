# The United States of College Football

Public preview: https://calbearsquared2025.github.io/college-football-attendance-site/

This repository contains the **static visualization and a restricted set of derived chart data**, exported from a separately maintained private research and validation pipeline. It does not contain the source database, bulk CFBD game records, NCAA reports, private reconciliations, or API credentials.

## Data-use and redistribution notice

The included JSON files exist to render the linked interactive visualizations. They are **not offered as a general-purpose dataset, public API, bulk download, or source-data redistribution license**. Please do not mirror, bulk harvest, package, or redistribute the files as a substitute attendance database or feed.

School-level 2026 cumulative weekly trends are **rounded to the nearest 500 spectators per game**. A separate 2026 home-game bar display includes exact attendance, week, date, opponent, and a link to the original university or conference report. Full source records, CFBD game IDs, raw responses, and historical individual-game data remain private. All 2026 attendance is provisional pending the final NCAA annual report.

Original data come from the NCAA, CollegeFootballData (CFBD), conference and university publications, and attributed historical sources. Their respective terms and rights continue to apply. This notice does not alter any third-party rights, create an exclusive claim to public facts, or imply that redistribution is risk-free.

See the [site methodology](https://calbearsquared2025.github.io/college-football-attendance-site/methodology.html) for sources, limitations, calculations, and known discrepancies. This is an independent research project, not an NCAA- or CFBD-endorsed publication.

## Project maintenance

The source pipeline is private. Static files in this repository are generated and reviewed before publication; do not add raw data or secrets to this public repository. Issues about the visualization can be raised here, but private source files should not be attached.
